# Compatibilidade legada — Knowledge Packs

Este caminho existe **somente para compatibilidade de leitura** com instalações antigas.

O nome oficial é **M.drives (Memory + Drives/Pendrives)** e novos conteúdos devem ser
criados em:

```text
knowledge/m_drives/
```

A STAR ainda pode descobrir `knowledge/packs` e a estrutura removível histórica
`STAR_KNOWLEDGE/packs`, mas o repositório não mantém cópias duplicadas dos M.drives
atuais aqui. O loader legado será removido apenas em uma migração futura explicitamente
versionada, depois que instalações antigas puderem ser atualizadas com segurança.
