# Voz rápida da STAR

A voz rápida padrão da STAR usa Piper local.

O instalador baixa automaticamente a voz `pt_BR-faber-medium` para esta pasta.
Os modelos não são versionados no Git para manter o repositório leve.

O Chatterbox permanece reservado ao modo opcional de voz clonada e usa o arquivo
local `voice/reference/star_reference.mp3` quando configurado na máquina.
