# ⚠️ COISAS QUE PRECISAM SER MELHORADAS ANTES DE CRESCER

Agora vem a parte importante: evitar retrabalho.

Existem algumas coisas que ainda não devemos ignorar.

---

# 1. Separar melhor o cérebro

Hoje:

```text id="izli6i"
brain.py
```

faz tudo.

No futuro precisa virar:

```text id="fxwxcz"
core/

├── brain.py
├── personality.py
├── reasoning.py
├── context.py
└── decision.py
```

Porque uma IA real precisa separar:

- personalidade;
- lógica;
- memória temporária;
- decisões.

---

# 2. Criar o sistema de personalidade

Isso é essencial para a ideia da garota virtual.

Criar:

```text id="fc2gtb"
core/personality.py
```

Exemplo:

```text id="kp2204"
Nome:
STAR

Humor:
calma

Estado:
feliz

Modo:
assistente

Tom:
amigável
```

A personalidade não deve ficar presa no código.

---

# 3. Criar sistema emocional

Para o avatar pixel art funcionar, a emoção precisa existir como dado.

Exemplo:

```text id="38uutd"
Emotion State

felicidade: 80%
energia: 60%
curiosidade: 90%
confiança: 75%
```

Então:

Usuário:
