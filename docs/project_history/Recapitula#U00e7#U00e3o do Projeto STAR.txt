# Antes de avançar

Ainda falta apenas confirmar um detalhe importante: **o primeiro commit**.

Na última conversa, o Git havia recusado o commit porque faltava configurar seu nome e e-mail.

Verifique se já fez isso. Caso ainda não tenha feito, execute:

```powershell id="zmqmsl"
git config --global user.name "Seu Nome"
git config --global user.email "seu_email@exemplo.com"
```

Depois:

```powershell id="269abe"
git add .
git commit -m "Estrutura inicial do projeto STAR"
```

E, se o repositório remoto já estiver configurado:

```powershell id="nv3ory"
git push -u origin main
```

Assim seu progresso ficará salvo também no GitHub.

## 💡 Uma recomendação para evitar retrabalho

Agora que a base está pronta, eu não seguiria adicionando apenas pequenos exemplos de código. Em vez disso, construiria a STAR como um software profissional desde o início, definindo uma arquitetura estável para que cada novo recurso (interface, memória, IA, voz e automações) seja integrado sem precisar reescrever partes importantes do projeto.

Isso tornará o desenvolvimento mais organizado e facilitará muito a evolução da STAR para a Kory.
